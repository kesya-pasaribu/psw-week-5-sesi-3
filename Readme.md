1. Cara Menjalankan Web

Untuk menjalankan web, langkah pertama adalah membuka folder web di Visual Studio Code. Setelah itu, buka file index.html. Klik kanan pada file tersebut, lalu pilih Open with Live Server. Setelah itu, web akan terbuka secara otomatis di browser.

2. Penjelasan Perubahan

Pada web ini, saya menambahkan menu Beranda, Kegiatan, dan Kontak agar tampilan web lebih lengkap. Saya juga mengubah warna judul menjadi merah muda, tombol menjadi ungu, dan card kegiatan menjadi hijau muda. Perubahan ini dilakukan agar tampilan web terlihat lebih menarik dan nyaman dilihat.

3. Hasil Pengujian

Berdasarkan hasil pengujian, web berhasil dibuka melalui browser. Bagian menu, profil, tujuan belajar, dan card kegiatan juga sudah tampil dengan baik. Namun, tombol salam dan menu navigasi masih perlu diuji lebih lanjut untuk memastikan semuanya dapat berfungsi dengan benar.
